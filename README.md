# Мои показания — Android MVP 0.3

## Изменения 0.3
- Автопоиск области после камеры/галереи. Для механических счётчиков с красной дробной
  частью ищутся соседние красные разряды; чёрные ячейки определяются слева от них.
- Выбор числа чёрных разрядов (4–8, по умолчанию 5). Его нужно выставить по счётчику.
- Если красные разряды не найдены, резервный поиск числовых строк через OCR.
  При таком поиске серийный номер может ошибочно стать кандидатом: проверяйте рамку.
- Показ найденной области на исходном фото и увеличенного фрагмента.
- Выравнивание небольшого наклона, контрастирование, пороговая и адаптивная обработки.
- Шесть OCR-проходов: полное окошко и нижние 75% без предыдущего барабанного ряда,
  каждый с тремя вариантами обработки. Принимаются только строки нужной длины.
- Цифры с пробелами собираются в одну строку; ведущие нули/дробная часть удаляются.
- Автоподстановка только при 3 и более совпадениях и отсутствии других вариантов.
  Это согласие обработок, а не вероятность правильности: требуется сверка с фото.

Это экспериментальная локальная обработка OpenCV + ML Kit, НЕ обученный детектор
всех моделей счётчиков. Для чёрно-красных барабанов поиск проверен локально на одном
предоставленном примере (область пяти чёрных цифр найдена автоматически). Качество OCR
на реальном Android пока не измерено. Блики, поворот на 90°, сильная перспектива,
переходные барабаны, другие цвета или число разрядов могут потребовать ручной правки.
Если распознавание не удалось, можно выделить область пальцем или ввести показание.
Фотографии не загружаются в репозиторий и не отправляются поставщику.

## Сборка
Используйте JDK 17, Android SDK 35, Gradle 8.9. Версия Android Gradle Plugin — 8.7.3.
Откройте корневую папку MeterScan в Android Studio. При необходимости выберите локальную
установку Gradle 8.9: бинарный Gradle Wrapper в этот архив не включён.
Для командной строки задайте ANDROID_HOME или sdk.dir в local.properties и выполните:

    gradle assembleDebug

APK: app/build/outputs/apk/debug/app-debug.apk.
Первичная сборка требует интернета для загрузки зависимостей.
Альтернативно загрузите содержимое MeterScan в корень своего GitHub-репозитория,
запустите Actions → Build Android APK → Run workflow и скачайте артефакт.
Workflow подготовлен, но здесь не запускался.

## Как пользоваться
1. Укажите имя счётчика, ресурс и тариф.
2. Сфотографируйте циферблат или выберите снимок.
3. Выделите только нужные цифры пальцем. Для сброса выделения нажмите на фото.
4. Нажмите «Распознать выделенную область».
5. Выберите число среди вариантов и исправьте при необходимости.
6. Нажмите «Подтвердить и сохранить».

## Ограничения и хранение
История хранится на телефоне без фотоархива. Экспорт JSON — через кнопку истории.
Удаление приложения удаляет историю, поэтому перед удалением экспортируйте записи.
Фото камеры находятся в кэше. Область/поворот/черновик могут сбрасываться при
пересоздании экрана. API поставщика ещё не подключён.

## Проверка сборки
APK собирается в GitHub Actions. Успех сборки не является проверкой распознавания
на телефоне. Нужно проверить фото/камеру, автопоиск, ручное выделение, отказ при
нечитаемом снимке, число разрядов, сохранение и JSON.

Использованы OpenCV (Apache-2.0) и Google ML Kit.
https://opencv.org/opencv4android-usage-models/
https://developers.google.com/ml-kit/vision/text-recognition/v2/android
