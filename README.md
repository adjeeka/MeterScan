# Мои показания — Android MVP 0.2

Исходный проект, не готовый APK. Требуется Android 9 или новее.

## Что реализовано
- Фото через установленное приложение камеры в полном разрешении.
- Выбор изображения через системный файловый диалог без доступа ко всей галерее.
- Учёт ориентации при декодировании, поворот на 90°, выделение области пальцем.
- Распознавание выделения с помощью встроенной модели Google ML Kit Text Recognition.
- Варианты чисел, исходный OCR-текст и обязательная ручная проверка.
- Название счётчика, вода/электричество/газ, тариф, редактируемое показание.
- Локальная история и экспорт JSON через системное меню «Поделиться».
- Значение хранится строкой: ведущие нули и дробная часть отбрасываются: 00124,900 → 124.

## Сборка
Используйте JDK 17, Android SDK 35, Gradle 8.9. Версия Android Gradle Plugin — 8.7.3.
Откройте корневую папку MeterScan в Android Studio. При необходимости выберите локальную
установку Gradle 8.9: бинарный Gradle Wrapper в этот архив не включён.
Для командной строки задайте ANDROID_HOME или sdk.dir в local.properties и выполните:

    gradle assembleDebug

APK: app/build/outputs/apk/debug/app-debug.apk.
Первичная сборка требует интернета для загрузки зависимостей.
Альтернативно загрузите содержимое MeterScan в корень своего GitHub-репозитория,
запустите Actions → Build Android APK → Run workflow и скачайте артефакт.
Workflow подготовлен, но здесь не запускался.

## Как пользоваться
1. Укажите имя счётчика, ресурс и тариф.
2. Сфотографируйте циферблат или выберите снимок.
3. Выделите только нужные цифры пальцем. Для сброса выделения нажмите на фото.
4. Нажмите «Распознать выделенную область».
5. Выберите число среди вариантов и исправьте при необходимости.
6. Нажмите «Подтвердить и сохранить».

## Границы первой версии
Это универсальное OCR, не обученная модель для конкретных счётчиков.
Блики, сегментные дисплеи, переходные положения барабанов и разделённые пробелами цифры
могут распознаваться неверно. Добавлено эвристическое подавление красных пикселей перед OCR; оно может ошибаться при бликах и цветном освещении. Надёжного автоматического определения дробных разрядов,
серийного номера и тарифа нет. При раздельных цифрах введите итоговое число вручную.
Фото обрабатывается на устройстве встроенной моделью. Приложение не отправляет показания
поставщику. Экспорт выполняется только по действию пользователя.
История хранит данные и OCR-текст, но не архив фотографий. Снимки камеры находятся
во временном кэше; удаление приложения удалит историю. Экспортируйте важные записи.
Выделение, поворот и неподтверждённое показание могут сбрасываться при пересоздании экрана.
Повторное сохранение создаёт новую запись. Редактирование/удаление истории и сравнение
с предыдущим показанием — следующие этапы.

## Проверка
В среде подготовки нет Android SDK/Gradle: сборка и запуск на телефоне не выполнены.
Проверены XML и состав архива. Перед использованием нужно собрать проект и проверить:
камеру (в том числе отмену), галерею, поворот фото, выделение, OCR без сети,
пустой результат, ручной ввод, сохранение после перезапуска и экспорт JSON.
Нужны реальные фотографии счётчиков для проверки точности.

Документация OCR: https://developers.google.com/ml-kit/vision/text-recognition/v2/android
